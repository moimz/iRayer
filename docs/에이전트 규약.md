# iRayer 에이전트 규약

iRayer 는 라이브러리의 영상 파일이 무슨 작품인지 **에이전트**에게 물어봐서 포스터·줄거리·출연진을 보여주고, 정해진 규칙대로 폴더를 정리합니다.

앱에는 TMDB 에이전트가 들어 있습니다. 그 밖의 에이전트는 이 문서를 따르는 웹 서버를 만들어 **사용자 정의 에이전트**로 추가할 수 있습니다. (예: 개인 영상용 메타정보 서버, 다른 메타정보 사이트를 쓰는 서버)

> 이 문서를 AI 에게 주고 "이 규약대로 에이전트를 만들어 줘" 라고 하면 만들 수 있도록 썼습니다.

- 규약 버전: **1**
- 앱 설정 → 에이전트 → 사용자 정의 에이전트 → **기본 주소**와 **API 키**를 넣으면 앱이 아래 요청을 보냅니다.

---

## 1. 기본 규칙

### 1.1 주소

에이전트는 **기본 주소** 하나를 가집니다. 모든 요청은 그 아래로 보냅니다.

```
기본 주소 : https://example.com/irayer
정보      : GET https://example.com/irayer/agent
매칭      : GET https://example.com/irayer/match?...
```

- 모든 요청은 `GET` 이고, 값은 주소의 쿼리 문자열(UTF-8, URL 인코딩)로 보냅니다.
- 한글은 NFC 로 보냅니다. (맥과 NAS 의 파일명은 자모가 나뉜 NFD 일 수 있어 앱이 NFC 로 바꿔서 보냅니다)

### 1.2 인증

앱은 모든 요청에 아래 헤더를 붙입니다. 에이전트는 서명을 확인하고, 맞지 않으면 거절합니다.

| 헤더 | 값 |
|---|---|
| `User-Agent` | `iRayer/2.0 (macOS)` 처럼 앱 이름/버전 |
| `X-iRayer-Time` | 요청을 만든 시각 (유닉스 초, 예: `1793507199`) |
| `X-iRayer-Signature` | 서명 (아래) |

**서명 만들기**

```
서명할 문자열 = 시각 + "\n" + 경로와 쿼리
서명         = HMAC-SHA256(키 = API 키, 문자열) 을 16진수 소문자로
```

- `경로와 쿼리` 는 실제로 보낸 그대로입니다. (예: `/irayer/match?kind=movie&hash=2679a30467df58d4&size=5396049345&path=...`)
- 에이전트는 시각이 **지금 ±300초** 안이고 서명이 같을 때만 받습니다. (예전 요청을 그대로 다시 보내는 것을 막습니다)
- API 키 자체는 보내지 않습니다.

PHP 로 확인하는 예:

```php
$time = $_SERVER['HTTP_X_IRAYER_TIME'] ?? '';
$signature = $_SERVER['HTTP_X_IRAYER_SIGNATURE'] ?? '';
$expected = hash_hmac('sha256', $time . "\n" . $_SERVER['REQUEST_URI'], $apiKey);
if (abs(time() - intval($time)) > 300 || hash_equals($expected, $signature) == false) {
    http_response_code(401);
    exit(json_encode(['success' => false, 'message' => '인증에 실패했습니다.']));
}
```

Swift 로 만드는 예 (앱이 하는 일):

```swift
let time = String(Int(Date.now.timeIntervalSince1970))
let message = Data((time + "\n" + pathAndQuery).utf8)
let mac = HMAC<SHA256>.authenticationCode(for: message, using: SymmetricKey(data: Data(apiKey.utf8)))
let signature = mac.map { String(format: "%02x", $0) }.joined()
```

### 1.3 응답

- 응답은 JSON (`Content-Type: application/json; charset=utf-8`) 입니다.
- 모든 응답에 `success` (true/false) 가 있습니다.
- 실패하면 `success: false` 와 사람이 읽을 `message` 를 줍니다. HTTP 상태 코드는 200 이어도, 401·404·500 이어도 됩니다.

```json
{ "success": false, "message": "작품정보가 없습니다." }
```

- 모르는 값은 `null` (배열은 `[]`) 로 줍니다. 필드를 빼지 마세요.
- 이미지 주소는 앱이 바로 받을 수 있는 **전체 URL** 입니다.
- 날짜는 `YYYY-MM-DD`, 시간 길이는 초(정수) 입니다.

## 2. 종류 (kind)

에이전트는 자기가 받는 **종류**를 정합니다. 사용자는 라이브러리마다 에이전트와 종류를 고르고, 앱은 그 라이브러리의 파일을 물어볼 때 종류를 함께 보냅니다.

| 필드 | 뜻 |
|---|---|
| `id` | 종류 고유값. 앱이 `kind` 로 그대로 돌려보냅니다. (영문·숫자 권장, 예: `movie`) |
| `name` | 화면에 보일 이름 (예: `영화`) |
| `type` | `MOVIE` (회차 없음), `SERIES` (시즌·회차 있음), `AUTO` (파일마다 에이전트가 정함) |

앱에 들어 있는 TMDB 에이전트의 종류는 `movie` (영화, MOVIE), `tv` (TV 시리즈, SERIES), `auto` (자동, AUTO: 파일 이름에 회차가 있으면 TV 시리즈, 없으면 영화) 입니다.
reader 에이전트는 여기에 `etc` (기타, 개인 영상) 를 더합니다. 종류는 꼭 보내야 합니다 (종류 없는 요청은 받지 않습니다).

## 3. 요청

### 3.1 `GET {기본주소}/agent` — 에이전트 정보 (필수)

앱이 에이전트를 추가할 때, 그리고 가끔 다시 부릅니다.

응답:

```json
{
  "success": true,
  "name": "reader",
  "version": "1.0.0",
  "protocol": 1,
  "kinds": [
    { "id": "movie", "name": "영화", "type": "MOVIE" },
    { "id": "tv", "name": "TV 시리즈", "type": "SERIES" },
    { "id": "auto", "name": "자동 (영화·TV 시리즈)", "type": "AUTO" },
    { "id": "etc", "name": "기타", "type": "MOVIE" }
  ],
  "relocations": true
}
```

| 필드 | 뜻 |
|---|---|
| `name` | 에이전트 이름 |
| `version` | 에이전트 버전 (자유 형식) |
| `protocol` | 따르는 규약 버전 (지금은 `1`) |
| `kinds` | 받는 종류 목록 (2장) |
| `relocations` | `/relocations` 를 지원하면 `true` |

### 3.2 `GET {기본주소}/match` — 이 파일은 무슨 작품인가 (필수)

| 값 | 필수 | 뜻 |
|---|---|---|
| `kind` | ✔ | 종류 `id` |
| `hash` | ✔ | 파일 해시 (OpenSubtitles 방식, 16자리 16진수 소문자, 5장) |
| `size` | ✔ | 파일 크기 (바이트) |
| `path` | ✔ | **라이브러리 폴더 기준** 경로 (예: `기생충/PARASITE.2019.1080p.mp4`, 시리즈는 `비밀의 숲/시즌 1/비밀의 숲.E01.mp4`) |
| `duration` |  | 재생 시간 (초) |
| `choice` |  | 사람이 `/search` 결과에서 고른 후보의 `id`. 있으면 찾지 말고 이 작품으로 정합니다. |
| `season`, `episode`, `episode_end` |  | 사람이 고른 시즌·회차·끝 회차 (한 파일에 여러 회차일 때 `episode_end`) |

에이전트가 할 일:

1. `choice` 가 있으면 그 작품으로 정합니다.
2. 없으면 경로·파일명·해시·크기·재생 시간으로 작품을 찾습니다. (해시를 기억해 두면 다음부터 바로 찾을 수 있습니다)
3. 확실하지 않으면 정하지 말고 후보를 돌려줍니다. 사람이 고르고 `choice` 로 다시 보냅니다.

찾았을 때:

```json
{
  "success": true,
  "matched": true,
  "item": { ...작품 (4.1) },
  "episode": null,
  "target": { "folder": "기생충 (2019)", "filename": "기생충 (2019)" },
  "relocations": []
}
```

시리즈 회차일 때는 `episode` 에 회차 (4.3) 를 넣습니다.

못 찾았을 때:

```json
{
  "success": true,
  "matched": false,
  "reason": "NOT_FOUND",
  "candidates": [ ...후보 (4.4) ]
}
```

| 필드 | 뜻 |
|---|---|
| `matched` | 작품을 정했으면 `true` |
| `item` | 작품 (4.1). 출연진 `authors` 포함 |
| `episode` | 시리즈면 이 파일의 회차 (4.3), 아니면 `null` |
| `target` | 이 파일을 옮길 위치 (4.5). 폴더 정리를 하지 않는 에이전트는 `null` |
| `relocations` | 함께 옮겨야 할 **다른** 파일들 (4.6). 없으면 `[]` |
| `reason` | 못 찾은 이유: `NOT_FOUND` (못 찾음), `EXCLUDED` (이 종류·경로는 다루지 않음) |
| `candidates` | 못 찾았을 때 고를 만한 후보 (4.4). 없으면 `[]` |

### 3.3 `GET {기본주소}/search` — 사람이 고를 후보 검색 (필수)

| 값 | 필수 | 뜻 |
|---|---|---|
| `kind` | ✔ | 종류 `id` |
| `query` | ✔ | 검색어 |
| `year` |  | 연도 |

```json
{ "success": true, "candidates": [ ...후보 (4.4) ] }
```

### 3.4 `GET {기본주소}/item` — 작품 상세 (필수)

| 값 | 필수 | 뜻 |
|---|---|---|
| `id` | ✔ | 작품 `id`, 또는 `/search` 후보 `id` |
| `kind` | ✔ | 종류 id (후보 `id` 일 때 분류로 씁니다) |

후보 `id` 가 오면 그 작품을 받아 두고 작품 정보를 돌려줍니다. 파일 없이 작품만 찾을 때 씁니다. (예: Apple TV 구입작)

```json
{ "success": true, "item": { ...작품 (4.1), "episodes": [ ...회차 (4.3) ] } }
```

`episodes` 는 시리즈일 때만 넣습니다. (영화는 빼거나 `[]`)

### 3.5 `GET {기본주소}/author` — 인물과 출연작 (필수)

| 값 | 필수 | 뜻 |
|---|---|---|
| `id` | ✔ | 인물 `id` |

```json
{
  "success": true,
  "author": { ...인물 (4.2) },
  "items": [
    { "id": "…", "type": "MOVIE", "title": "기생충", "title_origin": "기생충", "year": 2019,
      "poster": "https://…", "role": "DIRECTOR", "character": null }
  ]
}
```

`items` 는 이 에이전트가 아는 그 인물의 작품입니다. (연도가 늦은 것부터)

### 3.6 `GET {기본주소}/relocations` — 옮겨야 할 파일 (선택)

에이전트가 파일을 기억하는 경우에만 만듭니다. (`/agent` 의 `relocations: true`)
제목을 고쳤거나, 나중에 묶음(컬렉션)이 생겼거나, 정리 규칙이 바뀌어서 **지금 있어야 할 위치**가 달라진 파일을 돌려줍니다.

| 값 | 필수 | 뜻 |
|---|---|---|
| `kind` | ✔ | 종류 `id` |

```json
{ "success": true, "relocations": [ ...옮길 파일 (4.6) ] }
```

## 4. 데이터 모양

### 4.1 작품 (item)

```json
{
  "id": "6e9bc630-d5ac-11f1-9d00-247f2d1666d7",
  "type": "MOVIE",
  "kind": "movie",
  "source": "tmdb",
  "source_id": "496243",
  "title": "기생충",
  "title_origin": "기생충",
  "collection": null,
  "year": 2019,
  "date": "2019-05-30",
  "genres": ["코미디", "스릴러", "드라마"],
  "summary": "전원 백수로 살 길 막막하지만 사이는 좋은 기택 가족…",
  "poster": "https://image.tmdb.org/t/p/w500/….jpg",
  "backdrop": "https://image.tmdb.org/t/p/w1280/….jpg",
  "rating": "KR:15",
  "authors": [ ...인물 (4.2) ]
}
```

| 필드 | 뜻 |
|---|---|
| `id` | 작품 고유값. 이 에이전트 안에서 바뀌지 않아야 합니다. (앱이 `/item?id=` 로 다시 물어봅니다) |
| `type` | `MOVIE` 또는 `SERIES` |
| `kind` | 종류 `id` |
| `source`, `source_id` | 정보를 가져온 곳과 그곳의 번호 (예: `tmdb` / `496243`). 같은 작품을 알아보는 데 씁니다. 모르면 `null` |
| `title` | 화면에 보일 제목 (한국어 권장) |
| `title_origin` | 원제 |
| `collection` | 묶음 (예: 반지의 제왕 3부작). `{ "id": 119, "name": "반지의 제왕" }` 또는 `null` |
| `year` | 연도 (시리즈는 첫 방송 연도) |
| `date` | 개봉일·첫 방송일 |
| `genres` | 장르 이름 목록 |
| `summary` | 줄거리 |
| `poster` | 세로 포스터 이미지 주소 |
| `backdrop` | 가로 배경 이미지 주소 |
| `rating` | 관람등급 `나라:등급` (예: `KR:15`, `KR:19`, `US:R`, `US:TV-MA`). 한국 등급을 먼저, 없으면 미국 등급. 등급이 없으면 `""` (빈 글자), 에이전트가 등급을 다루지 않으면 `null`. 앱은 "성인 등급 숨기기" 에 씁니다 (KR 18·19·청소년관람불가·제한상영가, US R·NC-17·TV-MA) |
| `authors` | 출연·연출 인물 (순서대로 보여줍니다). `/match`, `/item` 에서만 넣습니다 |

### 4.2 인물 (author)

```json
{
  "id": "6ede5460-d5ac-11f1-ab80-199385e19702",
  "source": "tmdb",
  "source_id": "21684",
  "name": "봉준호",
  "name_origin": "봉준호",
  "photo": "https://image.tmdb.org/t/p/w185/….jpg",
  "items": 1,
  "role": "DIRECTOR",
  "character": null
}
```

| 필드 | 뜻 |
|---|---|
| `id` | 인물 고유값 (`/author?id=` 로 물어봅니다) |
| `source`, `source_id` | 정보를 가져온 곳과 번호 |
| `name` | 이름 |
| `name_origin` | 원어 이름 |
| `photo` | 사진 주소 |
| `items` | 이 에이전트가 아는 그 인물의 작품 수 |
| `role` | 이 작품에서의 역할: `ACTOR`, `DIRECTOR`, `WRITER` (작품 안에서만) |
| `character` | 배역 이름 (배우일 때만) |

### 4.3 회차 (episode)

```json
{
  "season": 1,
  "episode": 1,
  "title": "어제 생겼던 고장",
  "summary": "…",
  "date": "2006-02-03",
  "still": "https://image.tmdb.org/t/p/w300/….jpg"
}
```

- 스페셜은 시즌 `0` 입니다.
- `title` 은 회차 제목입니다. "1화", "에피소드 1" 처럼 번호뿐이면 `null` 로 주는 것이 좋습니다.

### 4.4 후보 (candidate)

```json
{
  "id": "496243",
  "type": "MOVIE",
  "title": "기생충",
  "title_origin": "기생충",
  "year": 2019,
  "summary": "…",
  "poster": "https://…"
}
```

`id` 는 사람이 고르면 앱이 `/match?choice=` 로 그대로 돌려보내는 값입니다.

### 4.5 옮길 위치 (target)

```json
{ "folder": "반지의 제왕/반지의 제왕 - 왕의 귀환 (2003)", "filename": "반지의 제왕 - 왕의 귀환 (2003)" }
```

- `folder` 는 **라이브러리 폴더 기준** 경로입니다. (`/` 로 구분, 앞뒤에 `/` 없음)
- `filename` 은 **확장자를 뺀** 파일 이름입니다. 앱이 원래 확장자를 붙입니다.
- 같은 이름의 자막 파일(`.smi`, `.srt` …)은 앱이 같은 이름으로 함께 옮깁니다.
- 같은 작품 파일이 여럿이면 앱이 이름 뒤에 ` - 2160p`, ` - 확장판`, ` - part1` 처럼 붙입니다.
- 파일·폴더 이름에 `\ / : * ? " < > |` 를 쓰지 마세요. (윈도우·SMB 에서 쓸 수 없습니다)

권장 정리 규칙 (앱의 TMDB 에이전트가 쓰는 규칙):

```
영화   : 제목 (연도)/제목 (연도).확장자
         묶음이 있으면 묶음이름/제목 (연도)/제목 (연도).확장자
시리즈 : 시리즈명 (첫방송연도)/시즌 1/시리즈명 - S01E01 (회차제목).확장자
         회차제목이 없으면 시리즈명 - S01E01, 스페셜은 스페셜/ 폴더
         한 파일에 두 회차면 S01E16-E17
```

### 4.6 옮길 파일 (relocation)

```json
{
  "hash": "2679a30467df58d4",
  "size": 5396049345,
  "path": "어떤영화 (2020)/어떤영화 (2020).mkv",
  "target": { "folder": "어떤영화/어떤영화 (2020)", "filename": "어떤영화 (2020)" },
  "to": "어떤영화/어떤영화 (2020)/어떤영화 (2020).mkv"
}
```

| 필드 | 뜻 |
|---|---|

## 5. 파일 해시

앱은 파일을 OpenSubtitles 방식으로 해시해서 보냅니다. 파일 이름이 바뀌거나 다른 폴더로 옮겨도 같은 값이라, 에이전트는 해시로 파일을 기억하면 됩니다.

```
해시 = (파일 크기 + 앞 64KB 의 8바이트 묶음 합 + 뒤 64KB 의 8바이트 묶음 합) 의 하위 64비트
       8바이트 묶음은 리틀 엔디언 부호 없는 정수, 16자리 16진수 소문자로
```

Python 예:

```python
import os, struct

def oshash(path):
    size = os.path.getsize(path)
    h = size
    with open(path, 'rb') as f:
        for offset in (0, max(0, size - 65536)):
            f.seek(offset)
            data = f.read(65536)
            data += b'\0' * (-len(data) % 8)
            for (v,) in struct.iter_unpack('<Q', data):
                h = (h + v) & 0xFFFFFFFFFFFFFFFF
    return '%016x' % h
```

해시가 같은 다른 파일이 나올 수 있으니 **해시와 크기를 함께** 열쇠로 쓰세요.
